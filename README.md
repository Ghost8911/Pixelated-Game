# Pixelated-Game

Hey, this is a game I made called **Zephrys**.

- **The Purpose:** I wanted to create something through which the user can have fun without installing any application.
- **The Idea:** I was playing Mario when I thought about this.
- **AI note:** Used AI to brainstorm ideas, debug jump/stomp quirks, and help polish UI layouts while writing and tuning the game logic myself.

## Controls
- **Move:** `A`/`D` or `ArrowLeft`/`ArrowRight` (or touch buttons `<` and `>` on phone/narrow screens)
- **Jump:** `W` / `Space` / `ArrowUp` (or `JMP` touch button, with coyote time and jump buffering)
- **Dash:** `Shift` or `K` (or `DSH` touch button)
- **Restart:** `R`
- **Mute SFX:** `M`
- **Quit / Toggle Pause:** `Q`

- **AI note:** Built a smaller single-screen version by hand as I typed it out; used AI sparingly for quick sanity checks.
